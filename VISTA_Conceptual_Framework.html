PROCESS / RUNTIME VIEW

VISTA (Virtual Interactive System for Tagum City)

1

User Request

User initiates a request by sending a multilingual chat inquiry.

USER
👤 💻 📱
Citizen Chat Interface (Web Browser / Mobile App)
👥
Citizen sends a question in English, Tagalog, or Bisaya via the interface.
Request
Response
2

Web Server

Web server receives the payload and routes it to the processing pipeline.

WEB SERVER
🖧
  • Receives HTTP/HTTPS POST request
  • Handles API routing (FastAPI)
  • Forwards text to application service
🌐
Web server handles the incoming request and routes it securely to the application service.
Request
Response
3

Application Service

NLP pipeline classifies the intent and applies confidence thresholds.

APPLICATION SERVICE
⚙️
  • Preprocesses text & extracts features
  • Classifies intent via ML NLP model
  • Evaluates confidence score (≥ 35%)
🧠
The NLP engine determines intent. If confidence is low, it triggers a fallback workflow.
Request
Result
4

Database

Database fetches the localized answer or logs the unresolved query.

DATABASE
🗄️
  • Retrieves localized intent answers
  • Stores chat logs & feedback
  • Logs unresolved queries
💿
Supabase PostgreSQL returns the translated answer or confirms logging of an unmatched query.
Response
Result
5

Response to User

FastAPI builds the final response and delivers it back to the interface.

RESPONSE TO USER
✅
  • FastAPI formats the JSON response
  • Web server returns HTTP response
  • User receives chatbot answer
💬
The chat interface renders the response (answer or fallback message) to the citizen.
